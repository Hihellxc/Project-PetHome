# คู่มือผู้ใช้ PetHome

คู่มือนี้อธิบายการใช้งานสำหรับผู้เยี่ยมชม ผู้ใช้ที่ลงประกาศ และผู้ดูแลระบบ

## 1. เริ่มต้นใช้งาน

เปิดเว็บไซต์ด้วยเบราว์เซอร์สมัยใหม่ หน้าแรกจะแสดงเฉพาะสัตว์ที่มีสถานะ **พร้อมหาบ้าน** ผู้เยี่ยมชมสามารถค้นหาและเปิดรายละเอียดได้โดยไม่ต้องสมัครสมาชิก

## 2. ค้นหาสัตว์

1. ใช้คำค้นเพื่อค้นจากชื่อ พันธุ์ หรือรายละเอียด
2. เลือกประเภท จังหวัด เพศ และช่วงอายุได้
3. ติ๊กตัวกรอง “ทำหมันแล้ว” หรือ “ฉีดวัคซีนแล้ว” หากต้องการ
4. กดดูรายละเอียดในการ์ดของสัตว์
5. เปลี่ยนหน้าเมื่อมีผลลัพธ์มากกว่า 12 รายการ

## 3. สมัครสมาชิกและเข้าสู่ระบบ

1. เลือก **สมัครสมาชิก**
2. กรอกชื่อ อีเมล และรหัสผ่าน
3. กลับไป **เข้าสู่ระบบ** ด้วยอีเมลและรหัสผ่าน
4. เมื่อต้องการออก ให้กด **ออกจากระบบ**

บัญชีจำเป็นสำหรับการลงประกาศ ดูคำขอของประกาศตนเอง และรายงานประกาศ แต่ไม่จำเป็นสำหรับการส่งคำขอรับเลี้ยง

## 4. ลงประกาศสัตว์

1. เข้าสู่ระบบแล้วเลือก **ลงประกาศ**
2. กรอกชื่อ ประเภท พันธุ์ เพศ อายุ จังหวัด และรายละเอียด
3. ระบุว่าทำหมันหรือฉีดวัคซีนแล้วหรือไม่
4. แนบรูป PNG/JPG/JPEG/GIF ได้ โดย request ต้องไม่เกิน 5 MB
5. ติ๊กยืนยันว่าข้อมูลเป็นความจริง
6. กด **บันทึกประกาศ**

หลังบันทึก ใช้ **ประกาศของฉัน** เพื่อเปิดดู แก้ไข หรือลบประกาศของตนเองเท่านั้น

## 5. ส่งคำขอรับเลี้ยง

1. เปิดหน้ารายละเอียดสัตว์ที่มีสถานะ **พร้อมหาบ้าน**
2. กรอกชื่อและเบอร์โทรศัพท์ ซึ่งเป็นข้อมูลจำเป็น
3. กรอกอีเมลหากต้องการรับอีเมลยืนยันและผลการพิจารณา
4. กรอกข้อมูลเสริม เช่น จังหวัด อาชีพ ประสบการณ์ ลักษณะที่พัก สมาชิกในบ้าน และข้อความถึงเจ้าของ
5. กดส่งคำขอ

ระบบจะบันทึกคำขอเป็น **รอดำเนินการ** และป้องกันการส่งซ้ำจากผู้สมัครคนเดิมต่อสัตว์ตัวเดิม หากเจ้าของตั้งค่าอีเมลครบ ระบบจะส่งอีเมลแจ้งเตือนที่เกี่ยวข้อง

## 6. จัดการคำขอสำหรับเจ้าของประกาศ

1. เข้าสู่ระบบแล้วเลือก **คำขอรับเลี้ยง**
2. อ่านข้อมูลผู้ขอและข้อความของแต่ละคำขอ
3. กด **อนุมัติ** เมื่อเลือกผู้รับเลี้ยงแล้ว หรือกด **ปฏิเสธ**
4. เมื่ออนุมัติ สถานะสัตว์จะเป็น **มีบ้านแล้ว** และคำขอที่ยังรอของสัตว์ตัวเดียวกันจะถูกปฏิเสธโดยอัตโนมัติ

ควรติดต่อผู้ขอผ่านข้อมูลที่ให้ไว้และตรวจสอบความพร้อมในการเลี้ยงด้วยตนเองก่อนส่งมอบสัตว์

## 7. รายงานประกาศ

ผู้ใช้ที่เข้าสู่ระบบสามารถเปิดหน้ารายละเอียดประกาศของผู้อื่น แล้วเลือก **รายงานประกาศนี้** เลือกเหตุผล และใส่รายละเอียดเพิ่มเติมได้ รายงานที่ยังรอตรวจสอบซ้ำสำหรับประกาศเดียวกันจะส่งเพิ่มไม่ได้

## 8. การใช้งานสำหรับผู้ดูแลระบบ

บัญชีที่มีบทบาท `admin` จะเห็นเมนู **ศูนย์แอดมิน**

- **ดำเนินการแล้ว**: ปิดงานรายงานโดยคงประกาศไว้
- **ยกเลิก**: ระบุว่ารายงานไม่ต้องดำเนินการ
- **ปิดประกาศ**: เปลี่ยนสถานะประกาศเป็นไม่ผ่านการตรวจสอบ

ควรตรวจสอบรายละเอียดและหลักฐานก่อนปิดประกาศทุกครั้ง

## 9. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เข้าหน้าจัดการไม่ได้ | ตรวจว่าเข้าสู่ระบบด้วยบัญชีที่ถูกต้อง |
| ส่งคำขอไม่ได้ | ตรวจชื่อ เบอร์โทร และสถานะประกาศ; ห้ามส่งคำขอซ้ำ |
| รูปไม่ผ่าน | ใช้ PNG/JPG/JPEG/GIF และลดขนาดให้ไม่เกิน 5 MB |
| ไม่ได้รับอีเมล | ตรวจ Spam และแจ้งผู้ดูแลให้ตรวจการตั้งค่า Resend |
| ประกาศไม่แสดงหน้าแรก | ประกาศอาจถูกอนุมัติรับเลี้ยงหรือถูกปิดโดยผู้ดูแล |
