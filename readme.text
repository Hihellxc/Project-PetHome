🐾 PetHome - ระบบรับเลี้ยงสัตว์ออนไลน์

📖 รายละเอียดโครงงาน

PetHome เป็นเว็บไซต์สำหรับช่วยให้เจ้าของสัตว์เลี้ยงสามารถประกาศหาบ้านใหม่ให้กับสัตว์ของตนเนื่องจากปัจจัยต่างๆที่ไม่อาจเลี้ยงต่อได้ 
และเปิดโอกาสให้ผู้ที่สนใจรับเลี้ยงสามารถค้นหาสัตว์ ดูรายละเอียด และส่งคำขอรับเลี้ยงผ่านเว็บไซต์ได้อย่างสะดวก 


---

🎯 วัตถุประสงค์

- เพื่อพัฒนาระบบรับเลี้ยงสัตว์ผ่านเว็บไซต์
- เพื่ออำนวยความสะดวกในการค้นหาสัตว์ที่ต้องการรับเลี้ยง
- เพื่อให้เจ้าของสัตว์สามารถจัดการประกาศของตนเองได้
